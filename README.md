# При открытии страницы в браузере загружается фронтенд на Angular. Во время старта, автоматически выполнаяет HTTP запросы /api/listings и /api/listings/count. После получения ответа, Angular обновляет свои данные 'listings' и 'listingsCount'. Изменение автоматически запускает обновление (вместо загрузка..., показывает найдено 5).
